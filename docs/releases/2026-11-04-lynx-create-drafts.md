# Lynx creation drafts

Enable “Plan a new guest” and describe a workload. Lynx can draft a built-in template with bounded integer CPU, memory (MiB) and disk (GiB) values using the configured OpenAI, Anthropic or OpenRouter model. The agent injects only public catalog fields. Custom templates, scripts, sources, options, infrastructure, addresses and credentials are excluded. Creation planning and selected-guest evidence cannot be combined.

Provider output is strictly validated, enriched with trusted catalog metadata and parsed before shortening chat text. Unknown templates, arbitrary fields and invalid values remain advice only. The AI route has no provisioning or infrastructure write operation.

“Review in Create” checks the current built-in catalog and opens the normal form with only suggested resource fields copied. A memory-only handoff is agent/template bound, expires after ten minutes and is consumed once. The normal template route is used; resource values and draft metadata stay out of URL query parameters, history state and browser storage. Replacing an already-open form requires confirmation. Failed catalog reads or unavailable templates preserve that form. Closing a pending review or changing navigation prevents late navigation; abandoning Create while its data loads discards the queued handoff.

The form keeps normal defaults for placement, networking, access and template options; those are not AI choices. A review checkbox gates the final explicit Create submission and resets after edits. Failed provisioning preserves the form. Existing manual creation remains available without the AI acknowledgment gate. No new dependencies, privileges or arbitrary shell tools were added.

Verification uses controlled provider/agent fixtures, never paid APIs or real guest creation. All 89 server/domain/integration tests, both TypeScript projects and the full production build pass. Browser fixtures cover creation review, guarded submission, failed/stale handoffs, replacement, Back/reload, mode changes, late responses and duplicate review clicks, with desktop/390px layouts. Existing chat, selected-guest setup, no-key companion and website presentation/companion checks pass. The existing expiry fixture now controls browser time around consent to avoid a one-second wall-clock race. Independent review identified a navigation race, reproduced and fixed with pending/queued-handoff regressions. Existing LAN agents need an update to use this feature.
